# 유튜브 음원 추출 (Youtube Audio Extractor) 🎵

유튜브 링크를 입력하여 고음질 MP3 음원을 간편하게 추출하고 저장하는 안드로이드 애플리케이션입니다.

## ✨ 주요 기능

- **유튜브 음원 추출**: 유튜브 URL을 통해 최고 음질의 오디오를 MP3 형식으로 변환 및 다운로드합니다.
- **간편한 UI**: 직관적인 입력창과 진행률 표시줄(ProgressBar)을 통해 다운로드 상태를 한눈에 확인 가능합니다.
- **공용 폴더 저장**: 추출된 음원을 내장 메모리의 `Download/유튜브 음원추출` 폴더에 저장하여 접근성을 높였습니다.
- **음악 앱 연동**: 삼성 Music 등 기본 음악 플레이어 앱에서 바로 인식할 수 있는 경로를 사용합니다.
- **폴더 바로가기**: 다운로드 완료 후 '다운로드 폴더 열기' 버튼을 통해 저장된 위치로 즉시 이동할 수 있습니다.
- **최신 상태 유지**: 앱 실행 시 자동으로 `yt-dlp` 바이너리를 업데이트하여 최신 유튜브 정책에 대응합니다.

## 🚀 기술 스택

- **Language**: Kotlin
- **Asynchronous**: Coroutines
- **Library**:
  - [youtubedl-android](https://github.com/yausername/youtubedl-android): 유튜브 영상/음원 추출 엔진
  - [ffmpeg-android](https://github.com/yausername/ffmpeg-android): 오디오 포맷 변환 및 인코딩

## 📂 설치 및 배포

### APK 설치
1. `app/build/outputs/apk/debug/app-debug.apk` 파일을 안드로이드 기기로 옮깁니다.
2. 기기에서 파일을 실행하여 설치합니다. (출처를 알 수 없는 앱 설치 허용 필요)

### 개발 환경 설정
1. 이 저장소를 클론합니다.
2. Android Studio (Hedgehog 이상 권장)에서 프로젝트를 엽니다.
3. Gradle Sync 후 실행합니다.

## ⚠️ 주의사항

- 이 앱은 개인적인 학습 및 연구 목적으로 제작되었습니다.
- 추출된 음원의 저작권 책임은 전적으로 사용자에게 있으며, 상업적 이용을 금합니다.
- 안드로이드 10 이상의 보안 정책(Scoped Storage)에 따라 파일 관리자 선택창이 나타날 수 있습니다.
