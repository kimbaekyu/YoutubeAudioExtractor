# 유튜브 음원 추출 (Youtube Audio Extractor) 🎵

유튜브 앱과 연동하여 고음질 MP3 음원을 가장 빠르고 간편하게 추출하는 안드로이드 애플리케이션입니다.

## ✨ 주요 기능

- **유튜브 앱 연동 (Share Intent)**: 유튜브 앱에서 '공유' 버튼을 통해 즉시 앱으로 링크를 전달합니다.
- **스마트 추출 확인 팝업**: 공유를 통해 앱이 열리면 자동으로 링크를 인식하고 추출 여부를 묻는 확인 창을 띄워 번거로움을 줄였습니다.
- **모던한 Material 3 디자인**: 카드 기반의 정돈된 레이아웃과 직관적인 UI/UX를 제공합니다.
- **공용 Music 폴더 저장**: 추출된 음원을 `내장 메모리/Music/유튜브 음원추출` 폴더에 저장하여 삼성 Music 등 모든 음악 앱에서 즉시 감상할 수 있습니다.
- **폴더 바로가기 (App Chooser)**: 다운로드 완료 후 사용자가 선호하는 파일 관리자 앱을 선택하여 즉시 폴더를 확인할 수 있습니다.
- **최신 yt-dlp 유지**: 앱 실행 시 백그라운드에서 자동으로 `yt-dlp` 엔진을 업데이트하여 최신 유튜브 정책 변화에 대응합니다.

## 🚀 기술 스택

- **Language**: Kotlin
- **Asynchronous**: Coroutines
- **UI Framework**: Material Design 3
- **Engine**: 
  - [youtubedl-android](https://github.com/yausername/youtubedl-android)
  - [ffmpeg-android](https://github.com/yausername/ffmpeg-android)

## 📂 설치 및 사용 가이드

### APK 설치
1. `app/build/outputs/apk/debug/app-debug.apk` 파일을 안드로이드 기기로 옮겨 설치합니다.

### 추천 사용 방법 (가장 편리함)
1. 유튜브 앱에서 원하는 영상의 **[공유]**를 누릅니다.
2. 공유 목록에서 **'유튜브 음원 추출'** 앱을 찾아 **길게 눌러 [상단 고정]** 합니다. (또는 편집 메뉴에서 즐겨찾기 추가)
3. 이제 항상 첫 번째 줄에 나타나는 앱을 클릭하고 **[추출 시작]** 팝업을 확인하면 끝!

## ⚠️ 주의사항

- 이 앱은 개인적인 학습 및 연구 목적으로 제작되었습니다.
- 추출된 음원의 저작권 책임은 사용자에게 있으며, 상업적 이용을 엄격히 금합니다.
- 안드로이드 10 이상의 보안 정책(Scoped Storage)을 준수합니다.
